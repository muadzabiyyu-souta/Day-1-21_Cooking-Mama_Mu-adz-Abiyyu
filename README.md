## Dokumentasi Kegiatan Workshop

### 1. Rangkuman Materi
*Berikut adalah materi yang disampaikan selama Day 1 mengenai "Building with AI, Managing Change with GitHub":*
- **Prompt Engineering**: Mempelajari cara merancang instruksi (prompt) agar AI memberikan hasil yang lebih baik, relevan, dan bisa digunakan[cite: 5]. Contoh struktur prompt yang baik harus mencakup *Role* (peran AI), *Task* (tugas), *Context* (konteks atau latar belakang proyek), dan *Format* (hasil yang diharapkan)[cite: 8]. Penggunaan prompt yang terstruktur ini penting untuk meningkatkan performa AI, mengurangi respons yang bias, meningkatkan kontrol, dan memberikan pengalaman yang lebih baik[cite: 11].
- **Pengenalan Git & GitHub**: 
  - **Git** adalah *version control system* (sistem pengontrol versi) yang diciptakan untuk melacak siapa, kapan, dan perubahan apa saja yang dibuat pada suatu file, serta mengelola kode secara lokal di komputer kita[cite: 13, 15].
  - **GitHub** adalah *platform* berbasis web yang digunakan untuk menyimpan repositori Git secara *online* dan sangat mendukung untuk kolaborasi *project*[cite: 15].
- **Git Workflow**: Terdiri dari tiga tahap utama, yaitu *Working Directory* (file yang sedang dikerjakan), *Staging Area* (tempat menyimpan perubahan yang akan di-*commit*), dan *.git directory/Repository* (tempat Git menyimpan semua data proyek)[cite: 14].
- **Perintah Dasar Git**: Mempelajari perintah-perintah *command line* dasar seperti `git init` (memulai repo baru), `git add` (memindahkan ke staging area), `git commit` (menyimpan file), `git push` (mendorong perubahan ke GitHub), dan `git pull` (mengambil perubahan dari GitHub)[cite: 16, 17].
- **Praktik Mandiri**: Melakukan instalasi Git, konfigurasi identitas Git, mengatur SSH key untuk keamanan, dan membuat aplikasi sederhana bernama "Student Task Planner" dengan bantuan AI, lalu menyimpannya ke GitHub[cite: 18, 22, 26, 27].
